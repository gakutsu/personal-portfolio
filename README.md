# Portfólio — Gustavo Akutsu Azzola da Silva

Landing page estática criada em HTML, CSS e JavaScript, pronta para hospedagem no GitHub Pages.

## Estrutura

- `index.html` — página única do portfólio
- `styles.css` — estilos e responsividade
- `script.js` — menu mobile, navegação ativa, animações e barra de progresso
- `assets/curriculo-gustavo-akutsu.pdf` — currículo disponível para abrir e baixar

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No GitHub, abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

## Antes de publicar

O currículo fornecido não contém e-mail, GitHub ou LinkedIn. Por isso, esses dados não foram inventados no site.
Na seção `#contato` do `index.html`, substitua a observação existente pelos seus links de contato quando desejar.
