# Portfólio — Gustavo Akutsu Azzola da Silva

Landing page estática criada em HTML, CSS e JavaScript, pronta para hospedagem no GitHub Pages.

O conteúdo profissional foi atualizado com base no currículo de 2026 e inclui atuação em gestão de clientes, growth, produto digital, análise de sistemas, desenvolvimento web, experiências profissionais, projetos, competências e 42 certificações/formações.

## Estrutura

- `index.html` — página única do portfólio
- `styles.css` — estilos e responsividade
- `script.js` — menu mobile, navegação ativa, animações e barra de progresso
- `assets/curriculo-gustavo-akutsu.pdf` — currículo atualizado disponível para abrir e baixar
- `assets/certificacoes-gustavo-akutsu.pdf` — documento complementar com as 42 certificações e formações profissionais
- `assets/gustavo-quem-sou-eu.jpg` — foto utilizada na seção “Quem sou eu?”

## Publicar no GitHub Pages

1. Envie todos os arquivos desta pasta para a raiz do repositório.
2. No GitHub, abra **Settings > Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde a publicação.
